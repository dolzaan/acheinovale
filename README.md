# AcheiNoVale

Marketplace hiperlocal de imóveis e freteiros, começando por Rio do Sul (SC).

## Rodar localmente

```bash
npm install
npm run dev
```

Abra `http://localhost:3000`.

## O que esta primeira entrega contém

- Home mobile-first e responsiva.
- Identidade visual inicial do AcheiNoVale.
- Dados fictícios realistas de Rio do Sul.
- Componentes de imóveis e freteiros prontos para reaproveitamento.
- Navegação mobile com ação de publicação em destaque.
- Modelo Prisma e documento de arquitetura do MVP.

Consulte `docs/ARQUITETURA_MVP.md` para o recorte, as rotas e a sequência recomendada.
